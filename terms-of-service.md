## 2. Description of Service

FreeBike GPS is a cycling navigation application for Android that provides:

- Turn-by-turn route navigation using on-device routing (BRouter)
- Offline and online map display
- Activity tracking and route recording
- Address and point-of-interest search

The **Free tier** includes online routing, map tiles, and address search.  
The **Premium subscription** (9.99 € / year) includes offline maps, offline routing, and offline address databases.
